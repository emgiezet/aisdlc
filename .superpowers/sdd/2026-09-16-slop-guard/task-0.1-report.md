## Concerns

### `author` field added to manifest (not in spec §4.2)

`claude plugin validate --strict` initially reported:

```
⚠ Found 1 warning:
  ❯ author: No author information provided. Consider adding author details for plugin attribution
✘ Validation failed (--strict treats warnings as errors)
```

The spec §4.2 does not include an `author` key, but the validator requires it in strict mode.
The field is not excluded by §3.1 (which only prohibits `permissions` and the unsupported
`settings.json` keys `agent`/`subagentStatusLine` in an incorrect context). Adding it satisfies
the declared acceptance criterion ("validate --strict green") without violating any spec
constraint.

Added as `"author": { "name": "Maksymilian Małecki" }` (object format — the plain-string format
also failed validation with "Invalid input").

**Recommendation:** update spec §4.2 to include the `author` field in the verbatim example.

# AI SDLC project profile

Facts about *this* repository that the AI SDLC pipeline skills would otherwise have to guess at.
Generated by the `init` skill; edit by hand whenever the answer changes. Commit it — an agent
reading a stale profile is worse than one that detects from scratch.

Most fields may be `none`, and `none` is a real answer: the commands skip the step instead of
inventing a substitute. The exceptions are the four under **Artefacts** — those always have a
value, because the pipeline has nowhere to put its output otherwise.

# AI SDLC project profile

Facts about *this* repository that the `/sdlc:*` commands would otherwise have to guess at.
Generated by `/sdlc:init`; edit by hand whenever the answer changes. Commit it — an agent
reading a stale profile is worse than one that detects from scratch.

Most fields may be `none`, and `none` is a real answer: the commands skip the step instead of
inventing a substitute. The exceptions are the four under **Artefacts** — those always have a
value, because the pipeline has nowhere to put its output otherwise.

## Artefacts

- **Specs live in:** `specs/` — always a real directory, never `none`. Change the path if this repo
  keeps such things elsewhere; `/sdlc:init` creates it either way.
- **Spec approval:** a human sets `status: approved` in the frontmatter. Nothing else may.
- **Branch naming:** `ai/<TICKET>-<slug>` for agent runs
- **Pull request label:** `ai-sdlc`
- **Default base ref:** `origin/main`
- **Briefs live in:** `specs/briefs/` — discovery artefacts (`/sdlc:brainstorm`, `/sdlc:discover`,
  `/sdlc:ux-shape`) that precede a spec.
